# Consciobite

Southeast Asia's first SKU-level carbon scoring and Digital Product Passport platform for food FMCG brands.

**Live demo:** [consciobite-app.onrender.com](https://consciobite-app.onrender.com) · **API docs:** [localhost:4000/api/docs](http://localhost:4000/api/docs) (dev only)

> The live demo runs on Render's free tier. First request after idle may take 30–60 seconds while the server cold-starts.

---

## The Problem

SGX-listed food manufacturers in Singapore face Scope 3 carbon reporting obligations under the SGX Sustainability Reporting framework. EU importers increasingly require Digital Product Passports (ESPR Regulation). No SEA-native platform exists to score food SKUs at the product level, track emissions across the supply chain, and generate regulatory-ready carbon documentation.

## What Consciobite Does

- **GreenGrade Algorithm** — Scores 550 food SKUs on a 0–10 scale using Gaussian Kernel Density Estimation across 7 supply-chain emission categories (Land Use Change, Animal Feed, Farm, Processing, Transport, Packaging, Retail). Uses variance-based feature importance, category-aware blending (60/40 category/global), and a sigmoid transform for resolution where products cluster.
- **Digital Product Passport API** — `GET /api/v1/passport/:productId` returns a structured JSON passport with GreenGrade score, percentile ranking, emission breakdown, data confidence tier, and carbon footprint per SKU. Ready for EU ESPR and SGX Scope 3 reporting.
- **Portfolio Scoring** — `POST /api/v1/portfolio/score` accepts up to 100 product IDs and returns the scored portfolio with category benchmarks, portfolio average, and highest/lowest performers. An ESG lead's entire range scored in one call.
- **Immutable Score Audit Trail** — Every score change is logged with product ID, old/new score, delta, methodology version, and timestamp. `GET /api/v1/audit/:productId` returns the full trail. Scores are generated by algorithm — when a brand asks "can you change my score," the audit log is the answer.
- **Governance Layer** — Independent Advisory Panel oversight, manufacturer onboarding with non-contingent fee acknowledgement, public transparency dashboard with aggregate score-change statistics. Addresses the conflict of interest between listing fees and independent scoring.
- **Barcode Scanning** — Look up any product's GreenGrade by barcode, with Open Food Facts fallback for 2M+ products.
- **Anomaly Detection** — Mahalanobis distance from category centroids flags outliers beyond the chi-squared 95th percentile for 7 degrees of freedom.

## Tech Stack

| Layer | Technology |
|---|---|
| API | Node.js 20, Express 4.18 |
| Database | SQLite via better-sqlite3 (WAL mode) |
| Scoring Engine | GreenGrade v3 — KDE + sigmoid scoring in Node.js |
| Frontend | Next.js 14 (App Router, static export), React 18, TanStack Query |
| Auth | JWT + bcryptjs, CSRF double-submit |
| Security | Helmet, CORS, HPP, rate limiting, account lockout, input validation |
| Infrastructure | Docker (multi-stage, non-root), GitHub Actions CI, Render.com |
| API Documentation | Swagger UI + swagger-jsdoc |

## Quick Start

```bash
git clone https://github.com/J-Dheeraj/Consciobite-Application.git
cd Consciobite-Application/backend
cp .env.example .env   # Set JWT_SECRET
npm install && npm run dev
```

Backend runs at `http://localhost:4000`. API docs at `http://localhost:4000/api/docs`.

Frontend (separate terminal):

```bash
cd frontend && npm install && npm run dev
```

Frontend runs at `http://localhost:3000`.

### Docker

```bash
export JWT_SECRET=your-secret-here
docker compose up --build
```

## Methodology

GreenGrade v3.0 uses Gaussian Kernel Density Estimation with Silverman bandwidth selection to score products relative to their category peers and the global catalog. Data sourced from Poore & Nemecek (2018) lifecycle assessments, Our World in Data, and Open Food Facts/Agribalyse.

Full technical specification: [`METHODOLOGY.md`](./METHODOLOGY.md)
